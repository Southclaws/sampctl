![sampctl-logo](docs/sampctl-wordmark.png)

sampctl manages dependencies, builds Pawn scripts, and runs SA:MP and open.mp
servers.

## Quick start

[Install sampctl](docs/install.md), then run these commands in your project directory.

```bash
sampctl init
sampctl ensure
sampctl run
```
